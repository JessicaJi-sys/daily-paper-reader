## 摘要
时间序列分类（TSC）在准确性与计算可扩展性之间存在明显的权衡。HIVE-COTE 2.0 等元集成方法可达到最先进的准确率，但需要大量计算；而超快随机卷积变换（如 MiniRocket、Hydra）可在数秒内运行，却难以应对相位无关分布、信号运动学以及类别数量较大时的决策树碎片化问题。

在本工作中，我们提出 CADENCE（Confidence-Adaptive Dual-Expert Network for time series Classification Excellence），一种统一的、CPU 原生双专家架构。CADENCE 将表示学习解耦为两条专用路径：（i）卷积线性专家，将 10,000 个确定性膨胀特征与闭式 L2 正则化 Woodbury 岭分类配对；（ii）分布区间专家，将竞争性膨胀核（Hydra）与跨信号运动学和 FFT 频带的二进 Cornish-Fisher 矩近似配对，并使用 ExtraTrees 集成进行拟合。带有稀有类别保留的内部验证元路由器动态选择纯专家路由与置信度加权软融合，随后在 100% 训练数据上完整重拟合。

在全部 109 个等长 UCR Archive 数据集上、30 次重采样（共 3,270 次运行）进行评估，CADENCE 达到 0.8864 的总平均准确率。这在整个 archive 中排名第 2，仅被 HIVE-COTE 2.0（0.8895，p_Holm = 0.295，无统计学显著差异）超过，同时优于 Hydra+MultiRocket（0.8818）、MultiRocket（0.8797）和 HIVE-COTE 1.0（0.8786，p_Holm = 0.048）。CADENCE 将与 HIVE-COTE 2.0 的差距缩小至 0.31 个百分点，同时在双核 CPU 上每个数据集平均仅需 17.53 秒。源代码与评估脚本：https://github.com/onisa-jr/CADENCE.git

## Abstract
Time series classification (TSC) exhibits a sharp trade-off between accuracy and computational scalability. Meta-ensembles like HIVE-COTE 2.0 reach state-of-the-art accuracy but require extensive compute, whereas ultra-fast random convolutional transforms (e.g., MiniRocket, Hydra) run in seconds but struggle with phase-independent distributions, signal kinematics, and decision tree fragmentation on large class counts.   In this work, we present CADENCE (Confidence-Adaptive Dual-Expert Network for time series Classification Excellence), a unified, CPU-native dual-expert architecture. CADENCE decouples representation learning into two specialized pathways: (i) a Convolutional Linear Expert pairing 10,000 deterministic dilated features with closed-form L2-regularized Woodbury ridge classification, and (ii) a Distributional Interval Expert pairing competing dilated kernels (Hydra) with dyadic Cornish-Fisher moment approximations across signal kinematics and FFT spectral bands, fitted with an ExtraTrees ensemble. An internal validation meta-router with rare-class preservation dynamically selects between pure expert routing and confidence-weighted soft blending, followed by a full refit on 100% of training data.   Evaluated across all 109 equal-length UCR Archive datasets over 30 resamples (3,270 total runs), CADENCE achieves a grand mean accuracy of 0.8864. This ranks #2 across the archive, surpassed only by HIVE-COTE 2.0 (0.8895, p_Holm = 0.295, no statistically significant difference), while outperforming Hydra+MultiRocket (0.8818), MultiRocket (0.8797), and HIVE-COTE 1.0 (0.8786, p_Holm = 0.048). CADENCE closes the gap to HIVE-COTE 2.0 to 0.31 percentage points while taking an average of only 17.53 seconds per dataset on a dual-core CPU. Source code and evaluation scripts: https://github.com/onisa-jr/CADENCE.git
