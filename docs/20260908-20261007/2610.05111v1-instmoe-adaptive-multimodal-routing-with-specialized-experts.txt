Abstract 

Multimodal inputs are inherently heteroge-neous, not only across modalities but also in the information pathways required for effec-tive prediction. To address this limitation, we propose InstMoE , an adaptive expert routing framework for multimodal learning. InstMoE dynamically routes each input to specialized unimodal and cross-modal experts, allowing the model to adapt its information pathways to the characteristics of the input. However, rout-ing can be misled when modality-specific vari-ations obscure task-relevant semantics. Such irrelevant variations may distort routing deci-sions, causing inputs to be assigned to inappro-priate experts. We therefore introduce a Con-trastive Semantic Alignment module, which encourages semantically similar inputs to share task-relevant representations while suppressing irrelevant modality-specific variations. Experi-ments on multimodal sentiment analysis bench-marks demonstrate that InstMoE achieves state-of-the-art performance on CMU-MOSEI and CH-SIMS v2 while using substantially fewer parameters than competitive baselines. Fur-ther analysis shows that different inputs exhibit distinct expert preferences, demonstrating that InstMoE moves beyond fixed fusion toward adaptive multimodal computation. 

1 Introduction 

A fundamental challenge in multimodal learning is that the importance of each modality is not fixed across inputs . A modality that provides a reliable signal for one input may be noisy or ambiguous for another. For example, text may clearly convey a user’s sentiment in some cases, whereas subtle acoustic or visual cues may provide more informa-tive evidence when the textual signal is ambigu-ous. Moreover, modality-specific variations, such as speaking style, background conditions, or fa-cial appearance, can alter the informativeness of individual modalities. This variability motivates adaptive routing that dynamically adjusts the con-tribution of different unimodal and cross-modal evidence pathways. Despite this variability, most existing mul-timodal models rely on fixed fusion architec-tures (Tsai et al., 2019; Zhang et al., 2023; Huang et al., 2024), processing different inputs through essentially the same computational pathway. This design implicitly assumes that modalities should contribute in a relatively consistent manner across samples. Such an assumption can be problem-atic: a dominant modality may overwhelm com-plementary evidence, while an unreliable modal-ity may inject noise into the fused representation. Although prior studies have explored modality-invariant representation learning (Hazarika et al., 2020; Wu et al., 2024a) and dynamic modality weighting (Feng et al., 2024; Hu et al., 2022), they typically focus on improving representations or adjusting modality contributions, rather than funda-mentally rethinking how multimodal inputs should be processed .This leads to a simple but important question: 

should every multimodal input really follow the same fusion pathway? We argue that an effective multimodal learner should adapt its computation to the characteristics of the input. Rather than uni-formly combining all modalities, it should identify task-relevant semantic information, assess the in-formativeness of available modalities, and route each input to the experts that are most appropri-ate for its multimodal evidence. Such adaptive computation allows the model to emphasize infor-mative modalities, suppress unreliable signals, and exploit complementary cross-modal interactions when needed. Motivated by this perspective, we propose In-stMoE , an adaptive expert routing framework 

that moves beyond fixed fusion through dynamic expert routing. A router dynamically determines how each input should be processed by a set of arXiv:2610.05111v1 [cs.CL] 4 Oct 2026 specialized modality-aware and cross-modal ex-perts. Consequently, different inputs can activate different expert combinations and follow different multimodal processing paths, enabling the model to adapt its fusion behavior to the available evi-dence. InstMoE is task-agnostic and can be applied to general multimodal learning problems. The main contributions of this work are summa-rized as follows: • Beyond Fixed Fusion. We propose InstMoE ,an adaptive multimodal routing framework that dynamically selects among specialized unimodal and cross-modal experts according to the characteristics of each input, moving beyond the shared fusion pathways adopted by conventional multimodal models. Specifi-cally, InstMoE identifies informative evidence pathways and adaptively combines them to construct an input-specific multimodal repre-sentation. • Adaptive Evidence Routing. We integrate contrastive semantic alignment with dynamic expert routing, aligning multimodal repre-sentations while adaptively determining how different information sources should be pro-cessed. This design improves routing robust-ness by reducing the influence of irrelevant modality-specific variations. • Effective and Parameter-Efficient Learn-ing. InstMoE achieves state-of-the-art perfor-mance on CMU-MOSEI and CH-SIMS v2 with only 3.53M parameters, demonstrating that adaptive multimodal computation can de-liver stronger performance with substantially lower model complexity. 

2 Related Work 

2.1 Multimodal Fusion 

Multimodal fusion has evolved from early and late fusion toward intermediate fusion , which ex-plicitly models cross-modal interactions. Exist-ing approaches employ tensor-based fusion (Zadeh et al., 2017; Liu et al., 2018), cross-modal atten-tion (Tsai et al., 2019), and gating or information-theoretic mechanisms (Rahman et al., 2020; Han et al., 2021b). Despite their diverse designs, these methods predominantly rely on shared fusion ar-chitectures with uniform information composition across instances. InstMoE instead enables adap-tive routing over specialized modality-aware and cross-modal experts. 

2.2 Multimodal Representation Learning 

Another line of work focuses on disentangling mul-timodal representations to better characterize the relationships between shared and modality-specific information. MISA (Hazarika et al., 2020), for ex-ample, separates modality-invariant and modality-specific representations to preserve both shared se-mantics and modality-specific characteristics. Sub-sequent studies have explored related decomposi-tion strategies to retain complementary modality-specific information during fusion (Yu et al., 2021; Wu et al., 2024a). More recently, (Jun et al., 2025) introduces Dynamic Gaussian Anchoring to encour-age attribute-separated latent units and improve the interpretability of disentangled representations, while (Pu et al., 2025) disentangles authenticity-related and event-specific representations in news content. 

2.3 Mixture of Experts (MoE) 

Mixture-of-Experts (MoE) architectures (Jacobs et al., 1991) enable conditional computation by routing inputs to specialized experts. Recent stud-ies have extended MoE to multimodal fusion and multi-task learning (Wu et al., 2024b; Zhang et al., 2025), while others have examined the special-ization and interpretability of MoE routing (Yang et al., 2025; Lo et al., 2025). However, existing approaches predominantly employ latent experts 

whose roles are learned implicitly. InstMoE instead defines experts according to modality-specific and cross-modal representations , providing semanti-cally structured choices for instance-level routing.

Building on this insight, InstMoE treats uni-modal and cross-modal representations as alterna-tive information pathways and dynamically selects the most relevant ones for each instance. In this way, In-stMoE adapts the information flow to individual instances rather than imposing a shared fusion pat-tern across all inputs.

4.3 Ablation Studies 

As shown in Table 5, the removal of the MoE module (replaced by direct feature concatenation) caused the largest performance drop (an F1-Score drop of 3.35%, from 84.87 to 81.52), validat-ing the critical role of dynamic fusion. Ablating the Semantic Alignment Loss (w/o Align Loss) led to the second-largest drop (an F1-Score drop of 2.82%, from 84.87 to 82.05), confirming the benefit of style-content disentanglement. The knowledge-guided initialization and auxiliary su-pervision losses also clearly contributed, with F1-Score drops of 1.74% ( w/o Centroid Init ) and 1.15% (w/o Aux Loss), respectively. The results demonstrate the effectiveness of the proposed mod-ule in multimodal sentiment analysis. Collectively, these results reveal a clear hierar-chy of component importance. As demonstrated, the removal of our two core conceptual innova-tions, specifically dynamic fusion (w/o MoE Mod-ule) and style-content disentanglement (w/o CA), induced the most significant performance degra-dation. We interpret this as strong evidence that these two components are the primary drivers of the model’s success, validating our hypotheses that models must dynamically fuse modalities and sepa-rate style from content. The other two components (w/o Centroid Init and w/o Aux Loss) function as crucial supporting strategies . We posit they sta-bilize and enhance the training process, ensuring the core MoE experts specialize effectively and the unimodal features are robust before fusion.

5 Instance-Adaptive Routing 

To evaluate whether InstMoE adapts its routing to modality reliability, we conduct controlled modal-ity degradation experiments. For each instance, we selectively degrade one or more modalities while keeping the others unchanged, using tem-poral masking for audio and visual features and span-level masking for text at ratios of 20% –80% .We then compare the routing weights of the original and degraded inputs using the same settings. The routing consistently shifts away from de-graded modalities. For example, degrading audio by 80% reduces the weight of audio-related experts from 31.4% to 14.7%, while increasing the weights of visual- and text-related experts from 34.2% and 34.4% to 41.6% and 43.7%, respectively. Similar shifts occur under visual and textual degradation, with the corresponding modality weights decreas-ing by approximately 15–18 percentage points. Un-der asymmetric audio-visual degradation, the rout-ing also responds to relative modality reliability, with the more severely degraded modality receiv-ing a larger reduction in routing weight. These results suggest that InstMoE reallocates compu-tation toward relatively more reliable modalities rather than merely responding to the presence of degradation.

5.2 Perturbation Robustness 

To assess whether semantic alignment reduces sen-sitivity to irrelevant modality-specific variations, we conduct a controlled perturbation study. We apply three acoustic perturbations—pitch shifting, speed perturbation, and additive noise—to the au-dio modality while keeping the linguistic content unchanged. These perturbations modify acoustic characteristics without intentionally altering the underlying sentiment. For each sample, we com-pare the model prediction on the original and per-turbed inputs. We report prediction consistency for each perturbation and the resulting accuracy change ∆Acc. Higher consistency and a smaller ac-curacy drop indicate greater robustness to modality-specific variations. As shown in Table 8, models with CA consis-tently achieve higher prediction consistency and smaller accuracy drops across both datasets. On MOSEI, for example, consistency under pitch, speed, and noise perturbations improves from 74.2, 71.5, and 69.8 to 85.4, 86.2, and 83.8, respectively, while the accuracy drop decreases from 6.7 to 1.7 points. These results indicate that semantic align-ment reduces sensitivity to superficial acoustic vari-ations while preserving the information needed for sentiment prediction.

Conclusion 

We propose InstMoE , an instance-adaptive mixture-of-experts-style framework with three key components: (1) a contrastive semantic align-ment module for reducing irrelevant modality-specific variations; (2) a dynamic MoE module 

with instance-adaptive routing across unimodal and cross-modal experts; and (3) a knowledge-guided initialization strategy for stable expert specializa-tion. Experiments on CMU-MOSEI and CH-SIMS v2 demonstrate state-of-the-art performance with substantially fewer parameters than competitive baselines. Further analysis confirms that InstMoE learns distinct expert preferences across instances, supporting effective instance-adaptive multimodal computation. Limitations 

Despite promising results, this study has certain limitations. First, the current implementation re-lies on pre-aligned, fixed-length input sequences, potentially limiting its use in real-world scenar-ios with unaligned or variable-length multimodal data. Second, our current implementation relies on standard BERT features to align with baseline protocols. Exploring the impact of more advanced pre-trained language models (e.g., RoBERTa, De-BERTa, or LLM-based embeddings) on expert spe-cialization remains a promising direction for future work. Third, style disentanglement is learned im-plicitly through the contrastive objective; the lack of explicit interpretability regarding the specific features designated as "style" requires further in-vestigation. 

Ethics Statement 

We utilize publicly available datasets (CMU-MOSI,CMU-MOSEI, CH-SIMS v2) which have been scrutinized for ethical standards. However, we acknowledge that sentiment analysis models can potentially be misused for surveillance or ma-nipulation if deployed irresponsibly. Additionally, while our model improves style disentanglement, it may still inherit biases present in the training data. We urge researchers to use this technology with discretion and primarily for analyzing aggre-gate user feedback or improving human-computer interaction.

Tensor-based Fusion Models 

• TFN (Zadeh et al., 2017) models uni-, bi-, and tri-modal interactions via tensor (Cartesian) fusion; • LMF (Liu et al., 2018) improves efficiency with low-rank factorization; • TETFN (Wang et al., 2024) further integrates text-centric tensor fusion within a Trans-former framework. 

Transformer and Attention-based Models 

• MulT (Tsai et al., 2019) leverages cross-modal Transformers to model interactions over unaligned sequences; • MAG-BERT (Rahman et al., 2020) injects audio-visual cues into pretrained BERT via multimodal attention and gating; • ALMT (Zhang et al., 2023) learns adaptive modality representations under language guid-ance. 

Disentanglement and Representation Learning 

• MISA (Hazarika et al., 2020) disentangles representations into modality-invariant and modality-specific components; • Self-MM (Yu et al., 2021) learns robust modality-specific features via self-supervised multi-task learning; • MMML (Wu et al., 2024a) extends decom-position with multiple specialized losses for optimized fusion. 

Other Fusion and Learning Strategies 

• BBFN (Han et al., 2021a) performs pairwise bimodal fusion prior to final aggregation; • MMIM (Han et al., 2021b) enhances fusion via mutual information maximization; • UniMSE (Hu et al., 2022) provides a unified framework for MSA and MER; • HyCon (Mai et al., 2023) leverages hybrid contrastive learning for tri-modal representa-tion learning; • CubeMLP (Sun et al., 2022) replaces Trans-formers with MLP-based fusion; • CENet (Wang et al., 2022) improves cross-modal feature enhancement; • TMBL (Huang et al., 2024) focuses on Transformer-based multimodal binding; • KuDA (Feng et al., 2024) introduces knowledge-guided dynamic attention; • KAN-MCP (Luo et al., 2025) explores explainable fusion via KAN and multi-perspective contrastive learning. 

Implementation Details We use pre-extracted features following standard protocols in prior MSA studies (Tsai et al., 2019; Hazarika et al., 2020). Text features are extracted with pre-trained BERT (Devlin et al., 2019), while CMU-MOSEI uses COVAREP (Degottex et al., 2014) and Facet for audio and visual features, respectively. For CH-SIMS v2, audio and visual features are extracted using openSMILE (Eyben et al., 2010) and Open-Face, respectively. Using fixed features enables us to isolate the effectiveness of the proposed InstMoE 

fusion architecture. We employ Nexp = 5 experts, including three unimodal and two cross-modal experts. The router is implemented as a residual MLP with a 4-head self-attention block, followed by a two-layer MLP to produce expert weights. The model is imple-mented in PyTorch and trained on a single NVIDIA 4060Ti GPU using AdamW (Loshchilov and Hut-ter, 2017) with a batch size of 32. Dataset-specific hyperparameters, including the learning rate and semantic alignment loss weight, are tuned with Optuna (Akiba et al., 2019); detailed settings are reported in Table 9 in Appendix. InstMoE uses pre-extracted features. Following standard protocols in prior MSA studies (Tsai et al., 2019; Hazarika et al., 2020), we adopt official pre-extracted features for fair comparison. Across all datasets, text features were extracted using a pre-trained BERT model (Devlin et al., 2019). Using fixed BERT representations allows us to isolate the performance gains of the proposed InstMoE fusion architecture. For the CMU-MOSEI datasets, au-dio features were extracted using the COVAREP toolkit (Degottex et al., 2014), while visual fea-tures were derived from Facet. For the CH-SIMS v2 dataset, audio features were extracted with the openSMILE toolkit (Eyben et al., 2010), and vision features were generated using OpenFace. Our model architecture uses Nexp = 5 experts as defined in Sec Expert Network Design (three unimodal and two cross-modal). The MoE routing module is implemented as a single fusion stage fol-lowing the feature encoders. The router network itself consists of a residual MLP with an atten-tion mechanism, comprising a projection layer, a self-attention block (4 heads), and a 2-layer MLP to compute the expert weights. Our model is implemented in PyTorch and trained on a single NVIDIA 4060Ti GPU. We use the AdamW opti-mizer (Loshchilov and Hutter, 2017) with a batch size of 32. Key hyperparameters, such as the ini-tial learning rate (e.g., 6.09 e−5 for CMU-MOSEI) and the semantic alignment loss weight ( λalign ), were optimized using Optuna (Akiba et al., 2019) for each dataset.
