## 摘要
构建图基础模型的一个核心障碍是输入在特征空间维度、语义和结构方面的异质性。这种异质性限制了图神经网络泛化到具有未见特征空间的新图的能力。我们通过SIGIL解决可迁移性挑战，该框架将任意属性图映射到固定维度的统一表示空间。给定一个图，SIGIL将其提升为结构交互图，其中节点是输入特征维度，加权、类型化的边编码跨图连通性多个阶数的特征对齐。关系消息传递网络将每个特征维度嵌入到共享空间中，将任意维度的原始节点特征转换为可迁移到任何下游图的表示。通过构造，SIGIL对节点、特征维度和标签的排列是等变的。此外，当输入特征是离散关系的一热指示符时，SIGIL恢复并严格泛化现有的知识图谱推理基础模型。在单个图上预训练的单个SIGIL模型即可实现强大的全归纳链接预测。此外，SIGIL可用于实现现有的知识图谱基础模型。因此，SIGIL在单一框架下统一了图基础模型设计中的几种现有范式。

## Abstract
A central obstacle in building graph foundation models is the input heterogeneity in terms of feature space dimensionality, semantics, and structure. Such heterogeneity limits the capability of graph neural networks to generalize to new graphs with unseen feature spaces. We address the transferability challenge with SIGIL, a framework that maps any attributed graph to a unified representation space of fixed dimension. Given a graph, SIGIL lifts it to a structural interaction graph, where nodes are the input feature dimensions and weighted, typed edges encode feature alignment across multiple orders of the graph's connectivity. A relational message-passing network embeds each feature dimension into a shared space, transforming the original node features, of arbitrary dimensionality, into representations transferable to any downstream graph. By construction, SIGIL is equivariant to permutations of nodes, feature dimensions, and labels. Additionally, when the input features are one-hot indicators of discrete relations, SIGIL recovers and strictly generalizes existing foundation models for knowledge graph reasoning. A single SIGIL model, pretrained on one graph, delivers strong fully-inductive link prediction. Also, SIGIL can be used to implement existing knowledge graph foundation models. As such, SIGIL unifies several existing regimes in graph foundation model design under a single framework

## 一、核心问题与研究动机

- **研究背景**：基础模型在语言和视觉领域取得了巨大成功，但在图结构数据上进展有限。原因在于图数据不存在类似文本的“通用词汇表”——每个图都有自己独特的节点特征空间，在维度、语义、标签集合上各不相同。一个在某张图上训练的模型，在一般情况下甚至无法“读取”另一张图。
- **核心挑战**：全归纳（Fully-Inductive）图模型需要同时跨三个轴泛化：**未见图结构、未见特征空间、未见标签空间**。现有工作分为两条独立研究线，各有局限：
  1. **节点分类专用GFM**（如GraphAny等）：可处理任意特征和标签空间，但无法处理链接预测。
  2. **知识图谱基础模型（KGFM）**（如ULTRA、TRIX等）：通过构建"关系图"实现了零样本推理，但本质上是**离散的**——假设有限的关系词表，无法处理连续特征。
- **关键洞察**：KGFM的关系图本质上就是构建在特征空间（关系类型）上的图。若能将此对象推广到连续特征空间，将统一两条研究方向。
- **论文目标**：提出 **Sigil** 框架，将任意属性图映射到固定维度的统一表示空间中，从而支持全归纳的链接预测和节点分类。

## 二、方法论：Sigil 框架

### 2.1 核心思想

给定任意图 \( G=(V,E) \)，Sigil 先将图提升为**结构交互图（Structural Interaction Graph, SIG）**——一个以特征维度为节点、以带权有类型边编码特征对齐模式的图。随后在 SIG 上运行关系消息传递网络，将每个特征维度嵌入到固定大小的共享空间中，从而将任意维度 \( d \) 的原始节点特征转换为固定维度 \( d_h \) 的统一表示 \( H = X\Theta^{(T)} \in \mathbb{R}^{n \times d_h} \)。由于模型参数仅作用于固定隐藏宽度，不依赖于输入维度，单个预训练的 Sigil 模型可应用于任意图。

### 2.2 SIG 的构建流程

1. **多阶特征传播**：对特征矩阵进行 \( K \) 次非参数传播：\( X^{(k)} = A^k X \)，获得不同阶数的特征视图。
2. **边缘特征提取**：在每个阶数 \( k \) 内，对每条边 \( (i,j) \) 用交互算子 \( g \)（如绝对差、逐元素乘法）计算边缘特征 \( x^{(k)}_{ij} = g(X^{(k)}_{i,:}, X^{(k)}_{j,:}) \)。
3. **角色聚合**：对每个节点，按邻居平均聚合并形成节点级特征摘要 \( \bar{X}^{(k)} \)（有向图则分离入边/出边通道，产生多个通道变体）。
4. **Gram 矩阵构建**：计算列间 Gram 矩阵 \( \bar{A}^{(k)} = (\bar{X}^{(k)})^\top \bar{X}^{(k)} \in \mathbb{R}^{d \times d} \)，该矩阵的每个元素衡量两个特征维度在局部邻域模式上的对齐程度。
5. **堆叠**：将各阶数（以及各通道对）的 Gram 矩阵沿阶数轴堆叠，形成带类型的 SIG：\( G_{\text{struct}} \in \mathbb{R}^{d \times d \times R} \)，\( R = 4(K+1) \)（有向图）。

### 2.3 在 SIG 上学习表示

- 初始化特征嵌入 \( \Theta^{(0)} \)（如 Laplacian Eigenmaps），然后通过关系消息传递网络更新：
  \[
  \Theta^{(t+1)} = \Theta^{(t)} W_{\text{self}} + \sum_{k=0}^{K} \bar{A}^{(k)} \Theta^{(t)} W_k
  \]
- 最终特征嵌入 \( \Theta^{(T)} \in \mathbb{R}^{d \times d_h} \) 将原始节点特征转换为统一维度：\( H = X\Theta^{(T)} \in \mathbb{R}^{n \times d_h} \)。

### 2.4 理论性质

- **定理1（严格泛化KGFM）**：当输入特征为离散关系的一热指示符时，SIG 的重建精确恢复了 KGFM 的关系图（ULTRA 的四类关系交互矩阵：h2h、t2t、h2t、t2h）。因此 Sigil 是 KGFM 从离散关系到连续特征空间的**严格泛化**；且通过多阶传播（\( k>1 \)）还能编码 KGFM 无法编码的高阶交互。
- **命题1（对称性）**：Sigil 生成的节点表示对**节点排列等变**、对**特征维度排列不变**；搭配等变解码器时对**标签排列等变**。

### 2.5 下游任务适配

- **链接预测**：Sigil-lp 将图结构信息和特征信号融合到 SIG 嵌入中，并搭配表达力强的链接预测 GNN（NBFNet）作为解码器，实现零样本推理。
- **节点分类**：Sigil-nc 输出固定维度的节点嵌入，再通过轻量 MLP 适配目标图的标签空间（全归纳表示学习）。

## 六、主要结论与发现

1. **链接预测**：在 7 个属性图基准上，**Sigil-lp 全部取得全归纳模型最佳结果**，且超过自己 NBFNet 骨干在直推式设置下的表现在 6/7 个图上（CiteSeer 例外）。最高提升达 15.80（AmazonPhotos）。在非属性图上，Sigil-lp 平均性能(73.54 Hits@50)高于 UniLP(72.10)，低于 TFMLinker(74.62)，但方差更低。
2. **知识图谱推理**：Sigil(0)（即只使用0阶SIG）可以**复现ULTRA**到接近程度（全归纳 MRR 差距 ≤2.1，Hits@10 差距 ≤1.2），验证了定理1；更高阶（Sigil(1)、Sigil(2)）在部分场景（inductive(e)组）一致提升 MRR 和 Hits@10，但在(e,r)组反而略降——表明更高表达力不总有益。
3. **节点分类**：Sigil-nc 平均准确率(66.10)高于 GraphAny(64.51) 和 TS-MEAN(65.09)，低于 TAG(71.57) 和 RGVT(71.78)；在 26 个数据集中取得 5 个最佳、10 个最佳或第二好。在异配图（如Actor、Roman、Minesweeper、AmzRatings）上表现突出，说明 SIG 嵌入具有跨域迁移能力。
4. **总体结论**：可迁移性、关系推理和边级任务可以从**单一机制**（SIG上的消息传递）同时产生，无需为每类任务分别设计。

## 七、方法或实验设计的优点

- **统一性**：将节点分类GFM和知识图谱基础模型两个表面上无关的方向统一到同一框架下，理论联系清晰（定理1），这在图基础模型文献中是新颖的。
- **对称性保证**：严格证明了节点排列等变、特征排列不变、标签排列等变的性质，为跨图泛化提供了理论基础。
- **无需预定义词汇表**：不同于处理文本/图时依赖 token 词表，Sigil 通过SIG将任意维度特征映射到固定大小空间，天生支持任意输入维度。
- **参数效率**：Sigil 模型参数不随特征维度 d 或图规模 n 增长（仅取决于固定隐藏宽度 \( d_h \)），与依赖大型表格基础模型的 TFMLinker 等相比更轻量。
- **多阶设计**：K 阶传播提供了对高阶结构交互的选择，并用消融实验表明不同图有不同最优 K。
- **理论到实证闭环**：从理论声称（KGFM泛化）到实证验证（复现ULTRA）形成了完整闭环。

- **节点分类性能弱于专用模型**：压缩特征空间至固定维度后，原始特征坐标对解码器不可达，需要更多监督才能达到专业模型的性能。

- **贡献总结**：Sigil 通过将属性图提升为结构交互图（SIG），首次将节点分类 GFM 与知识图谱基础模型统一到同一框架，理论证明了其严格包含 ULTRA 一类离散关系 GFM；实验表明一个预训练模型即可在链接预测、知识图谱推理、节点分类三大任务上实现全归纳泛化，且在许多基准上达到领先结果。
- **展望**：未来的工作可探索更高效的 SIG 近似（如低秩分解、采样）、将框架扩展到边特征与异质图、预训练数据的选择与多源预训练，以及将 Sigil 作为模块嵌入更大规模基础模型。
