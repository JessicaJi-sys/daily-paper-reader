## 摘要
大语言模型的扩展日益依赖混合专家（MoE）架构，以将激活计算量与总参数量解耦。然而，MoE 的有效性常受专家坍缩和表示冗余制约，二者都会导致模型容量未被充分利用。为应对这些挑战，本文提出分布正交化损失（DO-loss），这是一种辅助正则化方法，将关注点从静态权重多样性转向动态路由行为。通过将每个专家的 token 分配历史表示为高维二值负载签名，DO-loss 惩罚签名重叠，从而在防止专家坍缩的同时促进功能专业化。为使该算法设计与系统效率相匹配，我们进一步引入副本专家机制（REM），它通过两层策略改进负载均衡：在全局批次层面调整副本专家的放置，并在微批次层面进行实时 token 调度。实证评估表明，对于 4.8BA0.5B 和 30BA3B 的 MoE 模型，我们的方法在下游任务上优于所评估的路由算法，同时保持相当的训练效率。

## Abstract
The scaling of LLMs increasingly relies on MoE architectures to decouple active computation from total parameter count. However, the efficacy of MoE is often constrained by expert collapse and representation redundancy, both leading to underutilization of model capacity. To address these challenges, this paper proposes Distributional Orthogonalization Loss (DO-loss), an auxiliary regularization that shifts the focus from static weight diversity to dynamic routing behavior. By representing each expert's token assignment history as a high-dimensional binary load signature, DO-loss penalizes signature overlap to prevent expert collapse while encouraging functional specialization. To align this algorithmic design with system efficiency, we further introduce the Replica Expert Mechanism (REM), which improves load balancing through a two-tiered strategy: adjusting replica expert placement at the global-batch level and performing real-time token dispatching at the micro-batch level. Empirical evaluations demonstrate that our method outperforms the evaluated routing algorithms on downstream tasks for both 4.8BA0.5B and 30BA3B MoE models, while maintaining comparable training efficiency.

# 论文总结：Function Over Form: Distributional Orthogonalization in Mixture-of-Experts with Replica Expert Mechanism

## 1. 核心问题与整体含义

- **背景**：大语言模型（LLM）的扩展日益依赖混合专家（MoE）架构，通过稀疏激活在保持单 token 计算量恒定的同时扩展到万亿参数规模。
- **核心矛盾**：MoE 的有效性依赖足够的专家专业化，但训练早期出现的路由偏置会形成"热门专家获得更多 token → 更新更频繁 → 更加热门"的反馈回路，导致两类问题：
  - **专家坍缩（expert collapse）**：少数专家主导，其余专家闲置，有效参数量下降。
  - **表示冗余（representation redundancy）**：不同专家学到相似功能，覆盖相近语义域，浪费容量。
- **现有方法的割裂**：
  - 负载均衡损失（如 Switch Transformer 的 LBL）能缓解坍缩，但强制均匀分配会抑制专业化。
  - 权重空间正交化方法（如 Orth-loss）鼓励功能多样性，但不保证专家真正接收 token——专家可以相互正交却指向输入流形之外的区域。
  - 直接组合二者会产生冲突梯度，破坏训练稳定性；在输出空间施加正交约束又会带来显著的计算、通信和内存开销，难以适配标准分布式训练框架。
- **整体含义**：论文主张"功能重于形式"——应从**动态路由行为**而非静态权重多样性出发进行正则化；同时将负载均衡视为**系统层问题**，与路由目标解耦。核心设计原则是：路由目标只负责功能数据划分，负载不均交由副本调度等基础设施机制解决。

## 2. 方法论

### 2.1 分布正交化损失（DO-loss）

- **核心思想**：将每个专家的 token 分配历史编码为高维**二值负载签名** \(F_i \in \{0,1\}^m\)（\(f_{it}=1\) 表示 token \(t\) 选中专家 \(i\)），通过惩罚签名之间的成对 Hamming 距离过小（即路由重叠）来迫使专家分化。
- **零和约束（结构关键）**：Top-K 路由下每个 token 恰好置 K 位，因此批次内总成对 Hamming 距离固定为：
  \[
  \sum_{i=1}^{n}\sum_{j=1}^{n}\|F_i-F_j\|_1 = 2mk(n-k)
  \]
  在总和固定的前提下，最小化距离方差等价于驱动所有成对距离趋于相等。
- **自校正抗坍缩机制**：当部分专家闲置（\(F_i=0\)）时，零和约束迫使活跃专家之间距离增大，方差上升；最小化方差会惩罚这种配置。对闲置专家 \(i\) 的路由概率 \(p_{it}\) 的梯度为负，推动路由器重新激活闲置专家，形成负反馈自校正，无需显式负载均衡项。
- **STE 与代理损失**：离散分配阻断梯度，采用直通估计（STE）\(F_i \leftarrow P_i + \mathrm{sg}[F_i-P_i]\)。最终将损失分解为：
  - 幅度项 \(G_{ij}=\|F_i-F_j\|_1\)（detach）
  - 梯度方向项 \(C_{ij}=\sum_t p_{it}(f_{it}-f_{jt})\)
  - 归一化损失：\(\mathcal{L}_{DO}=\frac{1}{m^2k}\sum_{i,j}G_{ij}\cdot C_{ij}\)，归一化系数使损失尺度为 O(1)，可直接与交叉熵比较。
- **全局级正则化**：通过 All-Reduce 跨数据并行（DP）组同步距离矩阵 \(G_{ij}\)（幅度全局），梯度方向 \(C_{ij}\) 保持本地，得到 Global-DO-loss：
  \[
  \mathcal{L}^{(d)}_{global\ DO}=\frac{1}{m^2k}\sum_{i,j}G^g_{ij}\cdot C^d_{ij}
  \]
  总目标：\(\mathcal{L}_{total}=\mathcal{L}_{CE}+\lambda\cdot\mathcal{L}_{DO}\)，**不使用任何额外负载均衡辅助项**。
- **复杂度**：\(O(mn^2)\)，因专家数 \(n\)（64–256）远小于隐藏维度，开销可忽略。

### 2.2 副本专家机制（REM）

- **动机**：DO-loss 防止坍缩但不保证严格负载均衡——专业化必然带来 token 量差异。在专家并行（EP）部署中，过载 rank 成为拖慢整体吞吐的 straggler，并造成显存占用差异和 OOM 风险。
- **两层解耦控制**：
  - **全局批层副本分配**：利用"热专家身份跨步稳定"的性质，控制器在每个全局批边界基于历史负载统计，贪心地选择最轻载 rank 作为接收方，放置使 **Benefit Score** \(S(e,r_s,r_r,\tau)\) 最大的专家副本，直至所有副本槽位填满。\(S\) 定义为在理想阈值 \(\tau\)（所有 rank 平均负载）下接收方可接受的最优 token 数。
  - **微批层动态调度**：每个微批开始时通过 AllGather 同步各 rank 队列深度，调度器按队列深度从轻到重排序，执行 D 轮贪心分配，将 token 路由到得分最高的副本，以吸收滑动窗口均值捕捉不到的瞬时波动。AllGather 仅传输 \(|R|\) 个整数，开销相对 AlltoAll 可忽略。
- **训练轨迹不变性**：REM 纯属系统级调度，不改变数学训练轨迹。副本参数在每次前向前通过异步 P2P 通信同步（与计算重叠）；梯度在全局步后累积回原始 rank 求和；优化器状态仅存于原始 rank。1 万步精度测试确认梯度对齐至小数点后三位。

## 6. 主要结论与发现

- **Global-DO-loss 全面领先**：在 4.8BA0.5B 上，Global-DO-loss 在全部 7 项指标（6 benchmark + PPL）上均最优；在 30BA3B 上相对 Auxfree 和 Global-LBL 保持一致优势，验证了正交化目标而非单纯全局统计是增益主因。
- **正交化优于负载均衡**：DO 目标在 local 和 global 两个层级都严格优于对应的 LBL；Orth-loss 表现最差（因其参数空间正交不约束 token 分配，导致严重负载倾斜与坍缩风险）。
- **全局统计有效但非主因**：Global-LBL > Local-LBL，Global-DO-loss > DO-loss，说明更大有效批次带来更稳定的路由统计，但增益主要来自成对正交化目标。
- **专家行为三准则**：没有任何基线能同时满足路由果断性（高 Top-K 分）、表示多样性（低 CKA 非对角值）、负载均衡（平坦直方图）三项。Auxfree 负载最平但 CKA 冗余最高、路由最不果断；Orth-loss CKA 最稀疏、Top-K 最高但负载呈严重指数尾；DO-loss 兼得 CKA 稀疏与 Top-K 高分，且负载更可控；Global-DO-loss 在深层取得最低 CKA 均值与最小方差。
- **专家粒度越大收益越明显**：32 专家时 Global-DO-loss 略逊于 Auxfree，64/128 专家时反超且差距扩大，契合现代 LLM 向细粒度专家发展的趋势。
- **REM 有效恢复吞吐**：未加 REM 时 DO-loss 的 MaxVio 持续偏高（结构性专业化所致，非收敛慢）；单个副本即可关闭大部分吞吐差距并将 MaxVio 压至 Auxfree 以下，两个副本接近完美均衡。REM 在 H20/H800、EP8/EP16 全配置下优于 EfficientMoE 和 Pro-Prophet，吞吐接近 Auxfree 基线。
- **开销可控**：副本带来的显存增加为个位数百分比（仅静态参数副本，无额外激活内存），AllGather 通信仅传输 \(|R|\) 个整数，可忽略。
- **设计原则**：MoE 有效性与系统效率处于不同抽象层级，需分离机制；路由目标专注功能数据划分，负载不均交由系统级副本调度与容量感知分发解决。

## 7. 优点

- **概念创新**：将正交化从静态权重空间转向**动态路由行为**，用二值负载签名捕捉专家实际功能分工，避免"权重正交但功能重叠/闲置"的问题。
- **零和约束的优雅性**：借助 Top-K 路由的结构性质（总 Hamming 距离固定），仅最小化距离方差即可同时实现防坍缩与促专业化，且坍缩具有**自校正负反馈**特性，无需额外负载均衡项。
- **损失解耦设计**：将幅度 \(G_{ij}\)（可全局同步）与方向 \(C_{ij}\)（保持本地）分离，使全局级正则化仅需一次 All-Reduce 距离矩阵，通信开销极小；归一化系数使损失尺度 O(1)，便于与 CE 平衡。
- **算法与系统解耦**：REM 纯系统级调度，不改变数学训练轨迹（梯度对齐至三位小数），使路由目标可专注于功能划分，负载均衡交给基础设施，理念清晰且可迁移到晶圆级等不同硬件范式。
- **两层调度设计**：全局批层用历史统计做静态副本放置，微批层用实时队列深度做动态分发，兼顾长期均衡与瞬时波动，且微批层 AllGather 开销远小于 AlltoAll。
- **实验较全面**：双规模模型、六 benchmark、多组消融（系数/批次/专家数/副本数）、定量 CKA 分析、跨硬件跨并行配置的系统吞吐对比，结论有较强支撑。
- **实用性强**：λ 比典型负载均衡系数小约两个数量级，副作用小；内存与通信开销可忽略，易于集成到标准分布式训练框架。

## 8. 不足与局限

- **算力与可复现性信息缺失**：未披露 GPU 数量、节点规模、训练总时长/GPU 小时，难以评估实际资源门槛；预训练语料为专有 2T 数据，不可公开复现，存在数据分布偏差风险。
- **大模型对比基线有限**：30BA3B 仅对比 Global-LBL 和 Auxfree，未复现 Local-LBL、Orth-loss、Seq-LBL、EfficientMoE、Pro-Prophet 等，削弱了大规模结论的完整性。
- **超参敏感性**：DO-loss 系数 λ 的最优值随模型规模变化（4.8B 为 1e-5，2B 为 5e-6），需要针对新规模重新调参；论文承认高维成对约束引入的梯度方差大于标量负载均衡损失，λ 过大将压倒 CE 信号
